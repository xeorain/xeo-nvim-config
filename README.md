# xeo-nvim-config

:warning: Neovim configuration template based on
[XeoVim](https://github.com/xeorain/XeoVim) (>= 3.0.0) for personal use only.

## Tweaking

- Edit `init.lua` to change XeoVim installation mode and extend `lazy.nvim`
  settings.
- Edit `lua/config/bootstrap.lua` to tune bootstrap details or even alter
  bootstrap logic if necessary.
- Edit `lua/config/options.lua` to customize XeoVim options.
- Edit `lua/config/xeovim_extras.lua` to specify XeoVim extra modules.
